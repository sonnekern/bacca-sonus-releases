# Bacca Sonus - wydania

Publiczne wydania aplikacji **Bacca Sonus** z rodziny Bacca SongBook: konfiguracja i sterowanie sprzetem gitarowym
(M-Vave Pocket Amp, M-Vave Chocolate Plus, looper LEKATO Loop Stage) oraz tryb sceniczny.

Pliki do pobrania sa w zakladce [Releases](../../releases). Aplikacja sama sprawdza aktualizacje
(plik `version.json` w tym repozytorium) i pobiera wlasciwy plik dla swojej platformy.

| Platforma | Plik |
|---|---|
| Android | `BaccaSonus-v<wersja>-build<numer>.apk` |
| Linux | `bacca-sonus_<wersja>-build<numer>_amd64.deb` |
| Windows | `BaccaSonus-<wersja>-build<numer>-Setup.exe` |

Aplikacja jest darmowa.
